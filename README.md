# Openrole — Phase 1

Frontend-прототип международного сервиса поиска вакансий. Next.js App Router, React, TypeScript strict, Tailwind CSS. Интерфейс на английском языке.

## Запуск

Нужен Node.js 22.13+ (проверено на 24.12).

```sh
npm ci
npm run dev
```

Откройте http://localhost:3000 — главная перенаправляет на `/jobs`.

Для проверки с телефона в той же Wi-Fi сети запустите `npm run dev -- --hostname 0.0.0.0` и откройте `http://192.168.50.149:3000`. Этот адрес разрешён в `allowedDevOrigins` в `next.config.ts`, чтобы Next.js не блокировал dev-ресурсы. При смене IP обновите эту запись и перезапустите dev-сервер.

Production:

```sh
npm run build
npm start
```

## Возможности

- 40 демонстрационных вакансий, 13 категорий, 10 компаний.
- Поиск по названию, компании, технологиям и тексту.
- В поиске постоянно доступны запрос, география и формат работы. Дополнительные фильтры: категория, опыт, дата, зарплата и технологии.
- Header: Find Jobs и Companies. На узких экранах поля поиска переносятся на новые строки без скрытия; поддерживаются portrait/landscape и safe-area отступы.
- Четыре сортировки и пагинация по 8 вакансий.
- Параметры поиска в URL, browser back/forward, сохранение выдачи при возврате из вакансии. Локальные фильтры обновляют URL через native History API без повторного серверного запроса ([Next.js](https://nextjs.org/docs/app/getting-started/linking-and-navigating#native-history-api)).
- Настраиваемая визуальная система, компактный search-first layout, широкая выдача, кликабельные карточки с полной суммой зарплаты.
- `/companies`: 10 компаний из mock-данных с переходом к их вакансиям.
- Desktop sidebar с раскрывающимися группами, мобильный modal drawer с предварительным числом результатов, клавиатурное управление и Escape.
- `/jobs/[slug]`: описание, требования, преимущества, информация о компании и географические ограничения.
- Apply открывает демонстрационный careers URL в отдельной вкладке.
- Empty state, 404, error boundary, metadata и semantic HTML.

## Структура

```text
app/                    Маршруты, metadata и layout
styles/                 CSS: variables, base, components, pages
  tailwind.css          Подключение Tailwind и тема
components/             Header, footer, иконки и placeholder логотипа
features/jobs/          Типы, поиск/фильтры, карточки, панель фильтров
  filter-jobs.ts        Чистая логика фильтрации и URL-параметров
  jobs-explorer.tsx     Интерактивный поиск и состояние URL
  job-filters.tsx       Общие элементы desktop/mobile фильтров

tests/                  Unit и браузерные проверки
```

## Стили

Стили разделены по компонентам и страницам; адаптивные правила находятся рядом с соответствующим компонентом. Глобальные файлы импортируются отдельно в `app/layout.tsx`, поэтому DevTools показывает конкретный исходный CSS-файл. Общие значения — в `styles/variables/tokens.css`. Tailwind сохранён. Карта файлов и правила редактирования — в [styles/README.md](styles/README.md).

## Решения и ограничения прототипа

- Источник данных — локальные типизированные mock-данные. Backend, БД и API отсутствуют. Для будущей интеграции достаточно заменить загрузку данных и серверную обработку поиска, сохранив типы и компоненты.
- Mock-вакансии вымышлены; названия компаний используются для реалистичного прототипа. Зарплаты, требования и преимущества не являются утверждениями о реальных позициях. Apply ведёт на careers-страницы, а не на существующие вакансии.
- Даты вычисляются относительно времени серверного запроса, чтобы фильтры свежести оставались пригодными для демонстрации. Сервер передаёт единый снимок времени клиенту.
- Страна означает географическую доступность: Spain включает Spain, EU, Europe и Worldwide; UK не включает EU. Работа в офисе/гибрид остаётся отдельным фильтром. Право на работу и визовая поддержка не предполагаются автоматически.
- Зарплаты — gross annual pay. Диапазоны проверяются на пересечение. Выбор валюты исключает вакансии без зарплаты; валюты не конвертируются. Для зарплатной сортировки без валюты выбирается USD.
- Несколько технологий объединяются через AND; слова поиска также должны совпасть все.
- SEO foundation включает metadata, semantic HTML и чистые slug. Прототип намеренно имеет `noindex`, чтобы вымышленные вакансии не попадали в поисковые системы. JobPosting JSON-LD не публикуется.
- UI не зависит от внешних шрифтов, изображений, сервисов или библиотек компонентов. Playwright используется только для проверки.
- ESLint закреплён на 9.39.5: React-плагины текущего `eslint-config-next` пока несовместимы с API ESLint 10.

## Проверки

```sh
npm run lint
npm run typecheck
npm test
npm run build
npx playwright install chromium firefox webkit
npm run test:e2e
```

E2E запускает отдельный production-сервер на порту 3100 автоматически после сборки. Проверяет поиск, фильтры, URL/history, пагинацию, детали, Apply, 404, drawer и отсутствие горизонтального overflow на ширинах 280–1440 px в Chromium и WebKit. Скриншоты сохраняются в `test-results/`.

Следующий этап — NestJS backend, PostgreSQL, Prisma и синхронизация источников. Начинать **только после команды `START PHASE 2`**.
